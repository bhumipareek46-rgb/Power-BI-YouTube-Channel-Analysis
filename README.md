📊 Power BI YouTube Channel Analysis

📌 Project Overview

Power BI YouTube Channel Analysis is an interactive data visualization project designed to analyze YouTube channel performance and audience engagement.

The dashboard provides insights into views, likes, comments, subscribers, and video performance through interactive visualizations.

🎯 Project Objectives

* Analyze YouTube channel performance.
* Understand audience engagement.
* Track views, likes, comments, and subscribers.
* Identify video performance trends.
* Present meaningful insights using interactive dashboards.

🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* CSV Dataset

📂 Project Files

📈 Dashboard Features
